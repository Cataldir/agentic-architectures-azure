# Agentic Architectures on Azure

Public destination for the learner code companion to Agentic Architectures on Azure.

## Current status

The practical companion has not been authored and qualified for release. This repository currently contains this entry note only. It does not yet provide an installable or tested Azure platform.

The intended companion covers an inference boundary, a hosted application runtime, grounded retrieval, asynchronous coordination, infrastructure definitions, workload identity, network isolation, and operating evidence. Guided exercises and reference solutions will accompany the code. Cloud execution will require a separate bounded setup and cost plan.

The existing [Agents in Azure Playbook](https://github.com/Cataldir/agents-in-azure-playbook) provides adjacent architecture samples for three implementation paths. Its samples have their own instructions and license; they do not establish completion of this course companion.

## Learner route

Use the published release instructions once the code is available: clone the repository, qualify the declared local checks, review infrastructure changes and costs, complete a starter exercise, compare the reference solution, and extend one architecture boundary. No deployment or Azure execution is claimed by this entry note.

## Content and reuse

The companion is intended for reusable code, practical instructions, and exercises. Course narration, slides, books, and videos are outside this repository. The code release will include its license, dependency attribution, and data provenance. No code license or third-party redistribution rights are established by this note.
